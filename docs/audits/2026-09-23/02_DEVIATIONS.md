# 02 — Deviations: Ka0s Party Frame Enhanced v1.0.1

Audited against **Ka0s WoW Addon Standard v2.64.0 (2026-09-23)** at `314c95e`. Prefix **`PFE`**,
unchanged from the 2026-09-15 run. Recurring findings keep their IDs, and new ones start at PFE-12.

## Tally

**Basis.** The *headline* counts **root** deviations only. The *total* adds the four dependents filed
as `derived from <ID>` (listed under *Dependents*). One recorded register row is reported as stale
(PFE-10) and counts as an ordinary Low root, because the finding is the stale row itself and not the
behavior the row describes.

| | High | Medium | Low | Info | Total |
|---|---|---|---|---|---|
| **Headline** (roots only) | 0 | 1 | 11 | 6 | **18** |
| **Total including dependents** | 0 | 1 | 15 | 6 | **22** |
| **MUST failures — roots** | 0 | 1 | 10 | 0 | **11** |
| **MUST failures — including dependents** | 0 | 1 | 13 | 0 | **14** |
| **SHOULD failures — roots** (PFE-05) | 0 | 0 | 1 | 0 | **1** |
| **SHOULD failures — including dependents** (+ PFE-20a) | 0 | 0 | 2 | 0 | **2** |

The six Info roots are observations. None of them fails a MUST or a SHOULD, so none is in either
failure count.

**Verdict: minor deviations.** Nothing a player, their SavedVariables or their session can hit as an
error today. The one Medium is a stand-down survivor: a disabled addon still receives the Edit Mode
exit callback and arms two timers every time it fires. Every Low is a latent risk, a convention gap
or a doc/config defect. Each row below still names its MUST.

## Recorded decisions confirmed (not deviations)

- **Test mode row absent:** `options-ui-§15`'s exemption holds. Unlocking shows the placeholder content
  (`modules/Preview.lua:7-15`). Not filed.
- **`lock`/`unlock` verbs:** present and routed through the seam (`settings/Slash.lua:116-121`). They
  are a MAY either way.
- **Feature-verb refusal while disabled:** implemented for `resetposition`, `lock` and `unlock`
  (`settings/Slash.lua:86-93`). This is the §2 SHOULD, and it is met.
- **`LibKa0s-Schema-1.0` not adopted (#14):** v2.64.0 says a host's own schema seam is not #47 until a
  later version requires adoption. Not filed.
- **Launcher without a stub:** the reason is written down (`core/LauncherSetup.lua:27-34`), and both
  callers guard on `NS.Launcher`. This is a decision, not a gap.
- **`hooksecurefunc` / `HookScript` hooks surviving the stand-down** (`modules/Providers.lua:78-80,86`,
  `modules/RangeFade.lua:106-108`, `modules/TargetFrames.lua:252-253`): neither API can be undone, and
  each body gates itself on `suspended` / `active()` / `featureOn()`. This is the sanctioned exception.
- **Issue #1 (`state:will-not-do`, raid frames):** a product-scope decision recorded in
  `docs/scope.md:20-21`. It departs from no rule, so it owes no register row.
